# 1-2BR asset provenance

Every file below was copied as-is (no re-encoding) from `walid/Shenandoah/<folder>/` at the
repo root — Walid's raw supplied package for the Shenandoah Valley 1-2BR "Couples' Getaway"
buy box (`walid/Shenandoah/Shenandoah Buy Box.docx` + `walid/Shenandoah/readme.txt`).
Source filenames were anonymous UUIDs or generic descriptive names with zero overlap against
the market CSV's Listing_Title/Property ID columns (checked directly, confirmed no match) —
these are anonymous photo evidence, not named/identified comps, except for the three named
"Design / Top Designs" Airbnb links in `js/data.js`, which are verified separately against the
raw CSV by Property ID (Lakeside, Hygge mountain retreat, The Sparrow Luxury A-Frame) and carry
no photo of their own in this asset folder.

Every caption below was written after actually viewing the specific source file (not inferred
from its folder/filename) to avoid mis-describing image content.

## Note on uncurated material

`walid/Shenandoah/amenity positioning/` (1 AVIF file) is not mentioned anywhere in
`readme.txt` and its intended placement in the buy box is unclear. It was left uncurated
pending clarification from Walid, rather than guessing where it belongs or what it depicts.

## Note on a source-material inconsistency (Must-haves vs. Nice-to-haves)

The raw `Must-haves/` folder included one barrel-sauna photo (`29f8a23d-...jpg`), but the docx's
Nice-to-Have list (not Must-Have) is the one that names "Barrel Sauna." That photo is placed in
`nice-to-have/` on the page, alongside the `Nice-to-haves/` folder's own barrel-sauna photo, to
match the docx's own amenity classification rather than the raw folder it happened to ship in.

Clearwater / Seminole / Largo Market Presentation

Interactive market presentation for the Clearwater / Seminole / Largo short-term rental market analysis.

The site brings together market research, revenue positioning, property buy boxes, comparable-property evidence, and design and amenity recommendations in a visual presentation format.

Project Structure

* index.html — presentation entry point
* css/ — presentation styling and responsive layout
* js/ — presentation logic, charts, maps, and supporting data
* assets/ — property imagery and visual references
* data/ — supporting market and geographic data

Running Locally

From the project directory:

python3 -m http.server 8000

Then open:

http://localhost:8000

Deployment

The presentation is designed as a lightweight static site and can be deployed through GitHub Pages.

Purpose

This project explores a more visual and interactive way to communicate STR market research and acquisition recommendations across Clearwater, Seminole, and Largo, allowing the underlying analysis and supporting evidence to be presented together in one cohesive experience.

All images in this directory were copied from Ifraham's supplied 5BR package at
`~/repos/clearwater/ifraham/BuyBox_5BR/` (integrated into the presentation webpage on
2026-08-24) and re-encoded (max 1600px on the long edge, JPEG quality 78, following the
same convention as `assets/3br/SOURCE.md` and `assets/4br/SOURCE.md`) to reduce page
weight. The original AVIF/WEBP/JPEG package files are untouched — this is a copy, not a
move. No image was cropped or content-edited; only format/resolution/compression changed.

`MustHave/Beds|Pool|BackYard|GameRoom/`, `NiceToHave/MiniGolf|Pickleball|Playground|HotTub|MovieSaunaGolfsimulator/`)
are used below — none were dropped. `NiceToHave/Gym/` and a dedicated golf-simulator photo
were not present in the supplied package, so the Nice-to-Have Ranked section shows those
two rows with no image, consistent with the source PDF's own "insufficient sample" framing.

No Airbnb listing names, property IDs, addresses, or URLs were supplied with this package
— every image below is anonymized visual pattern/reference evidence for the 5BR Premium
Buy Box, not an identified, linkable comp. No revenue comp set, design-comp property
roster, Alexandria link, purchase-price candidate, or Zillow screen was supplied either;
the webpage's 5BR Revenue Potential, Purchase Price, Geographic Considerations, and Ideal
Locations sections say so explicitly rather than inventing figures or comps.

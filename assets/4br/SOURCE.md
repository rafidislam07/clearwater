# 4BR asset provenance

All images in this directory were copied from Rafid's 4BR research package at
`rafid/Clearwater_Buy_Box_4BR/design_comp_set/` and
`rafid/Clearwater_Buy_Box_4BR/low_tier_counterexamples/` (integrated into the
presentation webpage on 2026-08-23) and re-encoded (max 1600px on the long edge,
JPEG quality 78) following the same convention as `assets/3br/SOURCE.md`. The
source PNG files are untouched — this is a copy, not a move. No image was
upscaled; images already under 1600px on their long edge were re-encoded to JPEG
at their original dimensions.

The one exception to "no content change" is `low-tier-underprogrammed-pool.jpg`,
which was cropped (see its row below) to reduce visibility of an unidentified
person in the background, per explicit instruction. No generative editing was
used — this is a plain rectangular crop; the pool, deck, and house evidence the
caption relies on is fully preserved.

Full verification detail (quality checks, identity checks, and per-image
cautions) lives in `rafid/Clearwater_Buy_Box_4BR/FINAL_IMAGE_VERIFICATION.md`
and `rafid/Clearwater_Buy_Box_4BR/asset_manifest.csv`. This file is the
webpage-facing provenance map only.
